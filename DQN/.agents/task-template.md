# Task Template

## Goal

Describe the one bounded stage deliverable and its public interfaces.

## Acceptance Conditions

List chemical semantics, DQN behavior where applicable, test coverage, and style limits.

## Verification Results

Record focused tests, full pytest/coverage, mini-linter, and the resulting flowsheet when applicable.
